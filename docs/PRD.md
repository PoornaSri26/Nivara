# PRD --- Nivara

## Overview
Nivara is an evidence-informed mental wellness companion: deterministic safety orchestration, LangGraph-style CBT workflows, user-controlled longitudinal memory ("True Memory"), and an Emotional Intelligence Dashboard.

## Problem
Basic chatbots give generic advice and miss crises. Users need safe, structured, evidence-based support with agency over their data.

## Goals
- Detect and escalate crises (988/116 123/14416).
- Deliver CBT tools (thought records, behavioral activation, grounding).
- Give users audit/edit/delete control over memory.
- Provide longitudinal mood/distortion insights.

## Target users
Individuals seeking mental wellness support; not a replacement for clinical care.

## Features (MoSCoW)
Must have: safety gates, CBT modules, True Memory, mood dashboard.
Should have: weekly clinician summary, data export, daily check-in.
Could have: multi-language, therapist sharing.
Won't have (v1): diagnosis, medication advice.

## Out of scope
Diagnosis, medication dosage, delusion reinforcement.
